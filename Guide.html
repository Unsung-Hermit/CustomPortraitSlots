CustomPortraitSlots — Guide

Adds new pilot portrait slots for MechWarrior 5: Mercenaries. Offline page — open this file in a browser. You do not need Python.

What you need

  • Windows
  • In-game: RollCall or Pilot Overhaul Eternal (do not assume both together)

How to run commands

generate_slot.bat needs an Id and Sex, so you run it once from a small PowerShell window. Afterwards, baking and merging are double-clicks.

  1. In File Explorer, open the folder that contains this Guide.html (the toolkit root).
  2. Click the address bar, type powershell, press Enter. A blue or black window opens in that folder.
  3. Copy one of the example lines below, paste into the window, press Enter.
  4. When it finishes, close the window. Your new folder is under out\.

Tip: In PowerShell the leading .\ is required. Command Prompt (cmd) can use the same line.

Workflow

  1. Generate one slot (PowerShell, step above).
  2. Open out\CPS_{Id}\Resources\, put your image as portrait.png (or .jpg / .jpeg).
  3. Double-click bake_portrait.bat in that same out\CPS_{Id}\ folder.
  4. Copy that folder into the game’s MW5Mercs\Mods, enable it in the mod list, restart the game.
    Or gather several baked folders under MergeInbox (below) and double-click merge_slots.bat at the toolkit root first.

Id rules

  • Characters: letters, digits, underscore _ only. No hyphen -.
  • Length 1–32. Must start with a letter.
  • Case-insensitive uniqueness (collision checks ignore case).
  • Reserved: bare CPS / CPSPack; Ids starting with CPST_; Windows names like CON, PRN.
  • Recommended (not required): <AuthorShort>_<SlotName> — e.g. Ashenwright_MyAce01.

Invalid Ids make generate / merge fail (nothing is silently “fixed”).

Generate commands (by Sex)

Copy-paste shape (no full paths in the command):

.\generate_slot.bat {Id} -Sex {Sex}
.\generate_slot.bat My_Ace_01 -Sex Female
.\generate_slot.bat My_Ace_01 -Sex Male
.\generate_slot.bat My_Ace_01 -Sex Nonbinary
  • Output folder: out\CPS_{Id}\
  • If you omit -Sex, Sex becomes Nonbinary and a warning is printed.
  • If that output folder already exists, generation stops with an error. Add -Force to overwrite.

What one slot contains

AssetName
Texture2D{Id}
MWPortraitAssetPO_{Id}
MWPersonaAsset{Id}_Template
Plugin folderCPS_{Id}

Portrait tag: Portrait.CPS only.

Persona tags always include Persona.Role.Pilot, Persona.Use.Template, Persona.Use.Employable (needed for POE), and Persona.Sex.Female / Male / Nonbinary matching -Sex.

Random pilots: Because slots use Persona.Use.Employable, the game may also use them as appearance candidates for randomly generated pilots. That is expected. The cooked Persona stores Name / Callsign as {Id}, but random pilots usually get a new name, callsign, bio, and traits from the game, so those template strings typically do not appear on screen.

Bake

  1. In out\CPS_{Id}\Resources\, place portrait.png, portrait.jpg, or portrait.jpeg (.png wins if several exist).
  2. Double-click bake_portrait.bat next to that mod’s mod.json.
  3. The image is center-cropped to 512×512 DXT5. Non-square images lose edges. Transparent PNGs keep alpha.

No pak exists until bake succeeds. Restart the game after the mod is in Mods.

MergeInbox layout

MergeInbox/
  MyPortraitPack/          ← pack name = out folder / pak name / display name
    CPS_MyAce01/           ← baked individual slot folders only
    CPS_MyAce02/
  AnotherPack/             ← one double-click can process several packs
    CPS_Other01/
  • Double-click merge_slots.bat at the toolkit root (no arguments). A window opens, then pauses so you can read the result.
  • Only baked slots (with Paks\CPS_{Id}.pak) are merged; unbaked ones are skipped and listed.
  • Each slot keeps Plugins\CPS_{Id}\ inside the pack (paths are not rewritten).
  • Successful packs include PackCatalog.html (thumbnails + Id / Sex / tags + the copy-paste generate command).
  • When using a pack, disable the individual slot mods.

CustomPortraitSlots — ガイド（日本語）

MechWarrior 5: Mercenaries 向けに、新しいパイロット用ポートレートスロットを追加するツールキットです。このファイルをブラウザで開いて使います。Python は不要です。

必要なもの

  • Windows
  • ゲーム側: RollCall または Pilot Overhaul Eternal（併用は前提にしない）

コマンドの動かし方

generate_slot.bat だけは Id と Sex が必要なので、一度だけ小さな PowerShell 窓から実行します。そのあとの bake / merge はダブルクリックで足ります。

  1. エクスプローラーで、この Guide.html があるフォルダ（ツールキットのルート）を開く。
  2. アドレスバーをクリックし、powershell と打って Enter。そのフォルダで青い／黒い窓が開く。
  3. 下の例の1行をコピーして窓に貼り付け、Enter。
  4. 終わったら窓を閉じてよい。新しいフォルダは out\ の下にある。

補足: PowerShell では先頭の .\ が必要です。コマンドプロンプト（cmd）でも同じ行で動きます。

流れ

  1. 上の手順で1スロットを生成する。
  2. out\CPS_{Id}\Resources\ に画像を portrait.png（または jpg/jpeg）として置く。
  3. 同じ out\CPS_{Id}\ 内の bake_portrait.bat をダブルクリックする。
  4. そのフォルダをゲームの MW5Mercs\Mods に入れ、mod 一覧で有効化し、再起動する。
    まとめる場合は、先に bake 済みフォルダを MergeInbox（下記）へ入れ、ツールキットルートの merge_slots.bat をダブルクリックする。

ID 規則

  • 使える文字: 英数字と _ のみ。ハイフン - は不可。
  • 長さ 1–32。先頭は英字。大小文字を区別せず一意。
  • 禁止: CPS / CPSPack 単体、CPST_ で始まる ID、Windows 予約名（CON など）。
  • 推奨（強制しない）: 作者略称_スロット名（例: Ashenwright_MyAce01）。

規則違反の ID は generate / merge がエラー終了します（勝手に直して続行しません）。

生成コマンド（Sex 別）

.\generate_slot.bat {Id} -Sex {Sex}
.\generate_slot.bat My_Ace_01 -Sex Female
.\generate_slot.bat My_Ace_01 -Sex Male
.\generate_slot.bat My_Ace_01 -Sex Nonbinary
  • 出力: out\CPS_{Id}\
  • -Sex 省略時は Nonbinary（警告あり）。
  • 同名の出力フォルダがあるとエラー。-Force で上書き。

1スロットの中身

アセット名前
Texture2D{Id}
MWPortraitAssetPO_{Id}
MWPersonaAsset{Id}_Template
プラグインフォルダCPS_{Id}

Portrait タグは Portrait.CPS のみ。Persona は Pilot / Template / Employable（POE に必要）と Persona.Sex.*（-Sex に対応）。

ランダムパイロット: Persona.Use.Employable を付けるため、スロットはランダム生成パイロットの見た目候補にもなり得ます。仕様です。cooked Persona には Name / Callsign として {Id} を書き込みますが、ランダム生成ではゲーム側が名前・コールサイン・バイオ・特性を振り直すため、テンプレの文字列は画面上ほぼ出ません。

Bake

  1. out\CPS_{Id}\Resources\ に portrait.png / .jpg / .jpeg を置く（複数あるときは png 優先）。
  2. その mod の mod.json の隣にある bake_portrait.bat をダブルクリック。
  3. 画像は中央クロップで 512×512 の DXT5 になる。非正方形は端が切れる。PNG の透過は維持される。

bake が成功するまで pak はできません。Mods に入れたあとゲームを再起動してください。

MergeInbox

MergeInbox/
  MyPortraitPack/          ← パック名 = 出力フォルダ名 / pak 名 / 表示名
    CPS_MyAce01/           ← bake 済みの個別スロットだけ
    CPS_MyAce02/
  AnotherPack/             ← 同じダブルクリックで複数パックも可
    CPS_Other01/
  • ツールキットルートの merge_slots.bat をダブルクリック（引数なし）。結果を読めるよう窓が止まります。
  • bake 済み（Paks\CPS_{Id}.pak がある）だけ結合。未 bake はスキップして一覧表示。
  • 各スロットの Plugins\CPS_{Id}\ はそのままパック内に残る（パスは書き換えない）。
  • 成功したパックには PackCatalog.html（サムネ + Id / Sex / タグ + コピペ用生成コマンド）が付く。
  • パックを使うときは個別スロット mod を無効化する。
