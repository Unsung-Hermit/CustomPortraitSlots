# Tools

Scripts, frozen exes, `repak`, licenses, and cooked templates live here.

Templates go under `templates/` (Male / Female / Nonbinary sets). Each set holds the texture `CPST_Tex` and a Portrait + Persona pair, cooked from the Mod Editor template mod `CPSTemplate`.

`make_placeholder.py` generates the mod folder icon (`Resources/Icon128.png`). The shipped file is `assets/Icon128.png`; `generate_slot` copies it into each generated mod.
